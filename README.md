## ① 무엇을 하나요 (What)

<!-- 한 문장으로. "성적 CSV를 읽어 유효한 점수만 골라 냅니다." 처럼. -->
성적 CSV 파일을 읽고 무효한 점수들을 포함한 다양한 점수들 사이에서 유효한 점수만 골라 냅니다.
